# Corn Dog Blessy - Website UAS (v2)

## Penting untuk GitHub Pages
Pastikan struktur repo seperti ini (assets huruf kecil):
- index.html
- about.html
- product.html
- merchandise.html
- kontak.html
- assets/style.css, assets/script.js, assets/logo.png, dll

## Upload GitHub Pages
Settings → Pages → Deploy from branch → main → /(root)
